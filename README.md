# Python Sales Data Analysis

A beginner-friendly portfolio analysis of **synthetic** 2025 retail transactions.

## Contents
- `sales_analysis.ipynb`: Jupyter Notebook with data checks, KPIs and charts
- `sales_data.csv`: 240 simulated sales records

## Run locally
1. Install Python and Jupyter.
2. Run `pip install pandas matplotlib notebook`.
3. Keep the notebook and CSV in the same folder.
4. Run `jupyter notebook` and open `sales_analysis.ipynb`.
5. Select **Run All** and save to include chart outputs in the GitHub preview.

## Skills
Pandas, data cleaning, aggregation, Matplotlib, business KPIs.

**Disclaimer:** All records are synthetic and do not represent a real business.
